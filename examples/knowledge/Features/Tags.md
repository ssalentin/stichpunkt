# Tags

Tags come from frontmatter (`tags: [a, b]` or `tags: a, b`) and from inline hashtags like #inline-tag or #nested/tag. A `#123` or a hex-like number is not a tag.

- Click any tag to open its automatic page `/tag/<name>`: see #feature.
- A page named like a tag, or mapped in `CONFIG`, shows a "Pages tagged" list at the bottom: see [[Projects]] and [[index]].
- The left sidebar lists all tags.
