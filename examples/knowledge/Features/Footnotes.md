# Footnotes

Put a reference like this[^1] in the text and define it anywhere in the page. All definitions are collected at the bottom, numbered in order of first use, with a link back to the text.

A second note[^longer] shows that definitions may have several paragraphs, and a named label is fine.[^1] Reusing a label adds another back link.

[^1]: The short form is one line.
[^longer]: A longer footnote can contain **formatting**, `code` and [[Features/Wikilinks|wikilinks]].

    Indent following paragraphs by four spaces to keep them in the same note.

Footnotes inside an [[Features/Embeds|embedded]] page keep working: ids get a unique suffix so they never clash with the host page.
