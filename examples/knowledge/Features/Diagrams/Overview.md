# Diagrams

Diagrams are fenced code blocks; one registry maps the fence language to a renderer.

**In the browser (lazy, only on pages that use them):** [[Features/Diagrams/Mermaid]], [[Features/Diagrams/Vega-Lite]], [[Features/Diagrams/Math]].

**On the server through Kroki (SVG cached by hash):** [[Features/Diagrams/Kroki]] covers PlantUML, C4-PlantUML, Graphviz, D2, ERD, Nomnoml, Svgbob and Ditaa.

A broken diagram shows its error and its source, never a blank block: see [[Features/Diagrams/Errors]].
