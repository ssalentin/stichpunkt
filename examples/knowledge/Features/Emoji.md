# Emoji

Type `:shortcode:` to get an emoji: :tada: :rocket: :white_check_mark: :warning: :bulb: :fire: :heart: :+1:

The shortcodes follow the GitHub names. Unknown ones such as :not_an_emoji: stay as written, and code is never touched: `:tada:`.

| Group | Examples |
| --- | --- |
| Faces | :smile: :joy: :thinking: :sunglasses: :sob: |
| Gestures | :wave: :clap: :pray: :muscle: :eyes: |
| Status | :white_check_mark: :x: :warning: :no_entry: :question: |
| Work | :memo: :books: :calendar: :bar_chart: :bug: :wrench: |
| Nature | :sunny: :cloud: :snowflake: :seedling: :rainbow: |
| Food | :coffee: :pizza: :cake: :apple: :beers: |

Emoji also work in headings, table cells, [[Features/Callouts|callouts]] and link text.

> [!tip] Use them sparingly
> They are plain Unicode characters, so search and copy/paste behave normally.
